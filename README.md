# 息月

情绪日记与自我关怀网页。以 `design-reference/visual-reference.png` 为视觉标准，保留 Vue 原型的数据选项与流程，完善交互与本地持久化。

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址。生产构建与验证：

```sh
npm run build
npm test
npm run preview
```

## 演示流程

首页选择整体状态 → 选择情绪、强度、可选因素与日记 → 确认或调整情绪理解 → 选择关怀行动 → 练习 → 自主选择行动后反馈 → 保存 → 时间线和洞察自动更新。

- 没有个人记录时展示明确标注的示例；第一条真实记录保存后，只展示自己的记录。也可在“我的 → 隐私与数据”关闭示例。
- 节律呼吸为 2 分钟，吸气 4 秒、停留 4 秒、呼气 6 秒；支持暂停、继续、提前结束及计时结束自动进入反馈。
- 感官回归为 5 分钟，分段引导；散步为 10 分钟。
- 不写文字、不选择影响因素也可继续。只有明确确认理解后才能进入推荐；可以跳过行动保存感受。
- 行动反馈为“轻松了一些 / 差不多 / 更难受了一些”，不默认改善。可选的行动后情绪独立保存，不覆盖最初感受。
- 关闭记录弹层保留当前会话草稿；尚未保存的草稿不会跨刷新保留。

## 数据与限制

记录保存在当前浏览器当前站点的本地存储中，键为 `xiyue-records-v1`，偏好为 `xiyue-settings-v1`。数据不会上传，也未加密，没有账户或跨设备同步。更换域名/端口会使用独立存储。清理浏览器数据会清除记录，可在“我的”导出备份。

情绪理解是依据用户选择生成的本地规则文字，不调用远程模型，不作医疗诊断。提醒仅在应用打开时显示，不是系统后台推送。

洞察的趋势使用单独选择的整体状态，不使用情绪强度判断好坏。日期缺失保持空白。因素比例、行动次数与反馈均从当前时间范围的实际记录派生；关联观察只描述已记录的共现情况，不声称因果或未经记录的睡眠时长。

## 结构

- `src/App.vue`：导航、持久化、导出、偏好和记录草稿。
- `src/components/`：首页、记录流程、时间线、洞察、我的、详情及可替换插画与表情。
- `src/data.js`：选项、示例、验证、分组、统计与导出。
- `src/styles.css`、`src/flow.css`、`src/pages.css`：设计变量、布局及响应式样式。
- `tests/data.test.js`：状态含义、反馈统计、日期边界、存储验证和导出测试。
- `docs/implementation.md`：原项目审查、设计规则与分阶段检查记录。
- `docs/visual-audit.md`：视觉与交互验收记录。
