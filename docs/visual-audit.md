# 视觉与交互验收

验收基准：`design-reference/visual-reference.png`。桌面端在 1440 × 1000 视口检查，移动端检查 390 × 844 与 320 × 740。

## 视觉一致性

- 首页第一视觉层级是“你现在感觉怎么样？”，问候语、洞察和最近记录均降低层级。
- 全站采用奶油白、暖白、低饱和鼠尾草绿及少量杏、黄、粉、灰蓝状态色；正文使用深灰绿，没有大面积纯黑或紫色科技渐变。
- 左侧导航、选中背景、内容宽度、轻边框、圆角和自然留白均按参考图校准；阴影只用于弹层和轻微面板层次。
- 首页主情绪区和必要的交互面板使用卡片；时间线、设置、记录详情主要依靠留白与分隔线，避免所有模块都成为白色圆角卡片。
- 植物、叶片、猫、杯子、太阳和散步景观使用统一的低饱和组件化矢量插画，后续可替换为正式水彩素材。
- 所有用户可见内容均为中文；项目代码与说明中的技术名词不会出现在界面。

## 交互闭环

- 首页整体状态 → 情绪、强度、因素与选填日记 → 情绪理解 → 用户确认/调整 → 三项关怀行动 → 练习 → 三段式反馈 → 可选重新记录 → 保存。
- 不填写日记、不选影响因素可以继续；未选择主要情绪或未确认理解时不能跳过对应步骤。
- 节律呼吸按 4 秒吸气、4 秒停留、6 秒呼气，实际时长 2 分钟；感官回归与散步分别为 5、10 分钟。支持暂停、恢复和提前结束。
- 反馈不会预选，保存已完成行动前必须由用户选择“轻松了一些 / 差不多 / 更难受了一些”。
- 记录刷新后仍存在；时间线、详情和洞察随真实记录更新。导出生成带 UTF-8 字节顺序标记的中文 CSV，并防止日记文本被电子表格当作公式执行。

## 数据含义

- 整体状态与情绪强度分开保存。趋势只使用整体状态，缺少记录的日期保持空白。
- “什么对你比较有帮助”只依据行动后反馈；不根据强度前后差值推断改善。
- 规律文案只描述记录中存在的共现，不把“睡眠”标签改写成“睡眠不足”，也不声称因果。
- 示例记录有明确标记；第一条个人记录保存后，首页、时间线和洞察切换为真实记录。

## 响应式与可访问性

- 700 像素以下左侧导航变为固定底部导航，记录弹层变为全屏，内容转为单列。
- 320 像素四个一级页面均无横向溢出；记录表单底部操作保持可触达。
- 图表提供文字标题、说明与可键盘聚焦的数据点；表单包含标签，弹层支持 Escape，键盘焦点在关闭后返回触发控件。
- 动画遵循减少动态效果偏好；打开弹层时锁定背景滚动。

## 已知边界

- 记录只保存在当前浏览器本地存储中，没有账户、跨设备同步和加密数据库；界面已说明共享设备与清理浏览器数据的风险。
- 每日提醒只在网页打开时出现，不是系统级后台推送。
- 自绘矢量插画保持参考图气质，但不等同于参考图中原始水彩插画文件。
