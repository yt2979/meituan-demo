# 息月实施记录

## 当前项目审查

- 工作区只有视觉参考图与 Gemini 单文件 Vue 原型，原入口文件处于用户删除状态。保留两份参考文件，创建新的构建入口。
- 沿用 Vue 3、Lucide 图标、原型中的情绪和因素选项，以及记录 → 理解确认 → 关怀 → 反馈的状态流。
- 修复原型中的问题：未实际保存、详情为空、图表不更新、练习统一只有 30 秒、没有阻止跳过确认、强度下降被错误当作改善、没有实际导出。
- 原型界面不是最终标准，以视觉图右上角应用首页和下方流程页为准；左上角是品牌展示，保留其温暖质感，不新增营销页或导航。

## 设计规范

- 暖白底 #faf7f1，奶油侧栏 #f7f5ed，绿灰正文 #3f4c45，鼠尾草主色 #587964。
- 状态：灰蓝、杏粉、奶黄、淡金、浅绿。整体状态和情绪强度分开存储。
- 中文字体：Noto Sans SC、苹方、微软雅黑；正文 14–16，辅助 12–13，标题 24–32；字重 400/500/600。
- 间距 4/8/12/16/24/32/48；面板圆角 20，输入 12，按钮胶囊；阴影仅用于很轻的层次。
- 植物、叶片、猫和自然景观封装为插画组件，可替换；不添加外部图库和不相关插画。
- 桌面左栏，移动底栏；记录流程桌面居中弹层、移动全屏；减少动态效果偏好得到尊重。

## 实施次序

1. 审查现状、建立统一样式和应用导航。
2. 完成首页，打开浏览器截图，和参考图检查比例、颜色、层级。
3. 依次完成记录、理解、关怀、呼吸、反馈。
4. 完成时间线、洞察、我的；使用真实本地持久化和派生统计。
5. 响应式、键盘操作、数据异常、完整演示闭环验证及视觉审查。
